AMAN BIRTHDAY SURPRISE — SETUP

1. Extract this ZIP completely.
2. Open the extracted Aman_Birthday_Surprise folder in VS Code.
3. Keep these files together:
   index.html
   style.css
   script.js
   README.txt
   photos/

4. Put your 7 photos inside photos/ and rename them EXACTLY:
   photo1.jpeg
   photo2.jpeg
   photo3.jpeg
   photo4.jpeg
   photo5.jpeg
   photo6.jpeg
   photo7.jpeg

   Your photos can be JPEG/JPG, but the filenames above must end in .jpeg.

5. Right-click index.html in VS Code Explorer -> Open with Live Server.
6. Open the website in the browser.

IMPORTANT:
- Do NOT put the photos beside index.html. They must be inside the photos folder.
- Do NOT leave the old .jpg names if using this updated version.
- If Live Server is already open, save the files and refresh with Ctrl+Shift+R.
- The photos are loaded locally from your computer; they are not uploaded by this website.

The countdown is intentionally 1 real second per displayed minute, so the whole surprise stays practical.
